# 図解・チャートの選び方

文章より図のほうが早く分かるときだけ入れる。1つのDocに複数入れてよいが、1枚に詰め込まず、図1つにつき言いたいこと1つにする。

## 図解

| 図 | 向いている会議 | 作り方 |
|---|---|---|
| 進行タイムライン | 講座・研修など、時間の流れや段階がある | 横軸に時間。フェーズごとに色分けしたラベル、下に内容のカード |
| ロードマップ | 今後の計画・スケジュールの合意 | 上に月や四半期、領域ごとの横レーンに色付きバー。節目は◆ |
| 比較表・ポジショニング | 案の比較、競合との立ち位置 | 2軸の十字に各案を円で置く。自社や採用案だけ目立つ色 |
| カスタマージャーニー | 顧客の体験を扱う企画・商談 | 段階ごとの色付きヘッダー。行は行動／接点／気持ち／困りごと／施策 |
| 組織・役割の図 | 担当や体制を決めた会議 | 上から下への階層。役割ごとに色分け |

## チャート

**逐字録に出てきた数字だけで作る。** 数字が足りなければチャートにしない。単位と時点（いつの数字か）を必ず書く。

| チャート | 向いている数字 | 作り方 |
|---|---|---|
| 棒グラフ | 項目ごとの比較（店舗別の売上など） | `lark-cli skills read lark-whiteboard scenes/bar-chart.md` |
| 折れ線グラフ | 時間による変化（月ごとの推移など） | `lark-cli skills read lark-whiteboard scenes/line-chart.md` |
| 円グラフ | 内訳・割合 | Mermaidの `pie` で入れる |
| ファネル | 段階ごとの人数の減り方 | `lark-cli skills read lark-whiteboard scenes/funnel.md` |
| KPIカード | 目標と現状の数字 | 数値＋目標＋差を大きく出したカードを横に並べる（SVG） |

## 共通の見た目

- 背景は白、文字は濃い色。中央上にタイトル
- 角丸のカード、領域ごとに色分け。色は1図につき4〜6色まで
- 色は図形の塗りで表す（画板では文字の色が黒に固定されるため）
- 入れた後はプレビューで文字の崩れを確認する。事実と違う図、読めない図は出さない
