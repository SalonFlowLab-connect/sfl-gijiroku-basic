# 1枚サマリーの作り方

## 共通（画板・手描き どちらも）

1枚で会議全体が分かる密度にする。

- 16:9（画板は `viewBox="0 0 1600 900"`）
- 上部に会議名・日付
- ブロックは議題数に合わせて5〜7個（短い会議でも4個未満にしない）
- 各ブロック：見出し＋箇条書き3〜4点
- 中央付近に「結論」ブロックを1つ置き、視線を集める
- 下段に次の行動の横向きの流れ（番号つき3〜5ステップ）
- 数字・日付・固有名詞・条件は具体的に入れる。抽象語だけで済ませない
- 素材リスト（SKILL.md §4）から割り振り、作った後に項目の取りこぼしが無いか照合する

## 画板で作る（既定）

**型 `../assets/summary-template.svg` をコピーして、文字だけを差し替える。** 配置・色・アイコン・余白は型のまま使い、ゼロから描かない（見た目の水準をそろえるため）。完成したSVGをDocに `<whiteboard type="svg" path="@./summary.svg">` で入れる。

型の中身（1600×900）：

| 場所 | 入れるもの | 文字数の目安 |
|---|---|---|
| 上：タイトル・日付・参加者 | 会議名／日付（曜日）・長さ／参加者 | 会議名20字以内 |
| 1段目の3枚 | 左＝現状・課題（赤）、中・右＝決定（緑） | 見出し12字・各行18字以内×4行 |
| 2段目の左右 | 左＝未確定・検討中（黄）、右＝今後の方向（青） | 同上 |
| 2段目の中央 | 今日の結論（主役）＋ひとことのタグ | 結論14字以内×3行・タグ16字以内 |
| 下：次の行動 | 番号つきの3〜5ステップ。最後は次の節目（緑） | 上段＝担当｜期限（10字）・下段＝やること13字以内 |

- 枠の役割は会議に合わせて変えてよい（例：決定が1つなら1段目の右を「数字・実績」に）。色の意味は保つ：赤＝課題、緑＝決定・結論、黄＝未確定、青＝今後・行動
- 行が4つに満たないカードは、その行を消す（空の行を残さない）。5行以上になるなら言い回しを削る。カードの数・大きさは変えない
- 文字数の目安を超えるとカードからはみ出す（SVGの文字は自動で改行されない）。超えたら言い回しを短くする。1文字だけの行・単語の途中で切れる行は作らない
- 型にない内容（文字起こしに無い期限・「すぐ」などの補足）を足さない。行動の期限が言われていなければ「担当」だけにする
- **文字の色は指定しても黒になる**（画板はSVGの `<text>` のfillを無視する）。色は図形の塗りだけで表す
- 外部の画像・フォント・スクリプトを参照しない

入れた後は画板をプレビュー画像に書き出し、文字のはみ出し・重なり・崩れを目で確認する。崩れていたらSVGを直して入れ直す。プレビューは正方形で書き出され、下に余白が出るが、これは書き出しの仕様なので気にしない。

```bash
lark-cli skills read lark-whiteboard references/lark-whiteboard-export.md
```

## 手描きで作る（設定が `手描き` のとき）

画像生成が使える環境（例：Codexの画像生成）でだけ使う。使えなければ画板で作る。

- グラフィックレコーディング（グラレコ）風：白い紙、黒いペンの手描き文字、細い線画アイコン、控えめな蛍光ペンの色面。見出しの帯、番号つきの手順、吹き出しで区切る
- 光沢のあるイラスト、3D、グラデーション、大きなキャラクターは使わない
- ロゴは入れない（相手企業のロゴは、提供または許諾があるときだけ）
- 生成後に日本語の誤字・文字化け・事実の誤りを必ず目で確認し、あれば作り直す
